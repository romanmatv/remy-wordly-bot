# remy-wordly — Telegram-бот для игр в слова

Бот на [grammY](https://grammy.dev), собирается Webpack, хранит всё в SQLite (встроенный модуль `node:sqlite`, нужен Node.js 22.13 или новее — компилировать ничего не нужно).
Работает сразу в нескольких чатах: игра, использованные слова и счёт каждого игрока у каждого чата свои.
В блоке «в других чатах» команды `/stat` показываются только участники текущего чата (кто писал в нём или имеет в нём очки) — игроки из чужих чатов сюда не попадают.

## Игры

| Игра | Словарь | Правила |
|---|---|---|
| 🔤 Существительные | Существительные | Слово на последнюю букву предыдущего. Если свободных слов на эту букву нет — берётся предыдущая буква (вторая с конца) и т.д. Бот начинает со случайного слова. |
| 🏙 Города | Города | То же самое, но города. Здесь допускается ответ из двух слов: «Нижний Новгород», «Белые Столбы». |
| 🐊 Крокодил | Существительные + Прочее | Ведущий видит слово во всплывающем окне (кнопка «Показать слово»), может сменить его в любой момент. Угадавший получает 1 балл и 15 секунд эксклюзивного права стать ведущим, потом — любой. Если слово не угадали за 2 суток, бот раскрывает его и предлагает любому стать ведущим. Если загаданное слово удалили из словаря (`/delword`), раунд прерывается без очков, ведущий сбрасывается и любой может стать новым. |

Общие правила: за верный ответ — 1 балл; слова в одной игре не повторяются; регистр не важен,
«е» = «ё», знаки/цифры/смайлы отбрасываются; сообщения из нескольких слов не проверяются
(исключение — «Города»: до двух слов; лимиты задаются в `MAX_WORDS` в `src/config.js`).
Слова через дефис — одно слово: «Ростов-на-Дону», «вице-президент». Любое тире (–, —) считается
дефисом, пробелы вокруг него игнорируются («Ростов - на - Дону» = «Ростов-на-Дону»).
Если слово кончается на дефисную часть, следующая буква берётся по последней букве («Камень-на-Оби» → «И»).
Контекст игры хранится в БД и переживает перезапуск бота, пока игру не остановят.

## Команды

- `/startgame` — меню выбора игры
- `/stopgame` — остановить игру и показать счёт этого чата (Существительные, Города, Крокодил, Общий)
- `/stat` — счёт в этом чате + суммарный счёт участников этого чата во всех остальных чатах
- `/clearstat` — очистить счёт только в этом чате (счёт в других чатах не трогается)
- `/addword` — выбрать категорию кнопками, затем прислать слово (принимается только от вызвавшего)
- `/delword слово` — удалить слово из словаря (или `/delword` и прислать слово следующим сообщением)

### Скрытые команды

Не показываются в `/help` и в меню команд Telegram.

- `/seedbase` — загрузить слова из CSV-файлов (тот же механизм, что при создании БД). Слова, которые
  уже есть в базе, и повторы внутри файла пропускаются, в ответ приходит статистика по категориям.
- `/delwordsall` — удалить **все** слова из словаря. Требует подтверждения кнопкой (действует 2 минуты,
  нажать может только вызвавший). Счёт игроков не удаляется; идущие раунды Крокодила прерываются.

Если в `.env` задан `ADMIN_IDS` (id через запятую), эти команды работают только для указанных
пользователей, остальным бот на них не отвечает. Если `ADMIN_IDS` пуст — доступны всем.

## Запуск

```bash
npm install
cp .env.example .env      # впишите BOT_TOKEN
npm run build             # сборка webpack → dist/bot.js
npm start
```

При первом запуске, если файла БД (`data/wordly.db`) нет, бот создаёт его со всей структурой и
заполняет словари из CSV:

- `city.csv` — последний столбец, разделитель `;`, кавычки удаляются;
- `nouns.csv` — первый столбец, разделитель — табуляция → «Существительные»;
- `verbs.csv` — первый столбец, разделитель — табуляция → «Прочее».

Первая строка каждого CSV — заголовок. Перед добавлением каждое слово проверяется: если такое слово
уже есть в этой категории (без учёта регистра, ё/е и знаков), оно не добавляется — дубликатов не будет. Пути можно поменять в `.env` (например, `CITY_CSV=city_full.csv`).
Чтобы перезаполнить словари, удалите файл БД (счёт тоже удалится).

## Важно для групп

Чтобы бот видел ответы игроков в группе, отключите у него Privacy Mode:
@BotFather → `/mybots` → бот → *Bot Settings* → *Group Privacy* → *Turn off*
(или сделайте бота администратором группы). После смены настройки удалите и снова добавьте бота в группу.

## Структура

```
src/
  index.js            — бот, команды, кнопки, роутинг сообщений, таймер Крокодила
  config.js           — настройки и названия категорий
  db.js               — открытие/создание БД, схема, импорт CSV
  sqlite.js           — обёртка над node:sqlite
  csv.js              — парсинг CSV
  store.js            — запросы к БД
  normalize.js        — нормализация слов (регистр, ё/е, отсечение знаков)
  stats.js            — форматирование счёта
  games/chain.js      — Существительные и Города
  games/crocodile.js  — Крокодил
```

### Заметки

- Города из двух слов («Нижний Новгород») можно называть, и бот может с них начать. Города из трёх и
  более слов хранятся в словаре, но в игре не участвуют. Слова через дефис («Ростов-на-Дону») — одно слово.
- `/addword` в категорию «Города» принимает до двух слов, в остальные — одно.
- Существующая БД обновляется автоматически при запуске (версия схемы хранится в `PRAGMA user_version`).
- `/clearstat` и `/delword` доступны любому участнику чата.

## Запуск в Docker

Нужны Docker и Docker Compose. В папке проекта должен быть файл `.env` с `BOT_TOKEN`.

```bash
docker compose up -d        # запустить в фоне
docker compose logs -f      # смотреть логи
docker compose restart      # перезапустить (заново поставит зависимости и пересоберёт бота)
docker compose down         # остановить
```

При каждом запуске контейнер выполняет `npm install`, `npm run build` и стартует бота.
Используется образ `node:24-alpine`, исходники и CSV берутся из папки проекта.

База данных лежит в томе Docker `data` (внутри контейнера — `/data/wordly.db`) и не пропадает
при перезапуске и пересоздании контейнера. Чтобы пересоздать базу из CSV:

```bash
docker compose down
docker volume rm remy-wordly_data   # имя тома: <имя папки>_data, см. docker volume ls
docker compose up -d
```
